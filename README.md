# Vyra Studio (Phase 1)

Android app (Kotlin + Jetpack Compose): theme, logo, splash, onboarding, home dashboard,
settings (persisted), library placeholder. Recording/streaming modules arrive in later phases.

## Build APK on GitHub
1. Push all files (including `.github/`) to a repo's `main` branch.
2. Open the **Actions** tab -> "Build APK" run.
3. Download `VyraStudio-debug-apk` from **Artifacts**, unzip, install the `.apk`.

If the build fails, copy the red error lines from the log and send them back.
